# LHS Creator Network CRM

Production CRM for LHS Creator Network.

## Production stack

- **GitHub:** source control
- **Supabase:** PostgreSQL, Auth, Row Level Security, Storage
- **Vercel:** application hosting
- **Google Sheets:** external operational sources where intentionally retained, including A/B League battle sheets

## Build rule

The backend is stabilized and verified before the final UI/UX pass. Database changes are versioned in `supabase/migrations`.
